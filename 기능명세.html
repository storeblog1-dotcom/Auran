Aura+n 기능 명세서

본 문서는 FastAPI 백엔드와 React Native 프론트엔드로 구축된 Aura+n 서비스의 전체 아키텍처, 데이터 모델, 미디어 엔진 및 RESTful API 엔드포인트 명세를 수록한 공식 기술 문서입니다.

1. 프로젝트 개요 & 기술 아키텍처

🐍 Backend Stack
• Framework: FastAPI (Python 3.11+ ASGI)
• Database: PostgreSQL / SQLite + SQLAlchemy 2.0 (Async)
• Migration: Alembic 비동기 마이그레이션
• Auth: JWT (Access Token + Refresh Token)
• Image: Pillow (EXIF 보정 & 1080px 리사이징)
📱 Frontend Stack
• Framework: React Native / Expo (TypeScript)
• Navigation: React Navigation (Tab & Stack)
• State Management: React Context API (AuthContext)
• Storage: AsyncStorage 로컬 토큰 보관
• UI/UX: Instagram UI 가이드라인 준수
🔐

2. 인증 & 세션 관리 모듈 (Auth)

기능명 기능 설명 적용 기술 & 엔드포인트
회원가입 Username, Email, Password, Full Name 입력 및 유효성 검증 후 계정 생성 POST /api/v1/auth/register (bcrypt 단방향 암호화)
로그인 & 토큰 발급 사용자 인증 성공 시 Access Token(단기) 및 Refresh Token(장기) 이중 토큰 발급 POST /api/v1/auth/login
토큰 자동 갱신 만료된 Access Token을 Refresh Token으로 백그라운드 재발급 POST /api/v1/auth/refresh
내 정보 조회 및 자동 세션 현재 세션의 유저 정보 반환 및 앱 재실행 시 토큰 자동 복원 GET /api/v1/auth/me (AuthContext 연동)
👤

3. 사용자 프로필 & 소셜 그래프 (Users & Graph)

기능명 기능 설명 엔드포인트
프로필 상세 조회 유저의 게시물 수, 팔로워/팔로잉 수, 소개글(Bio), 프로필 이미지 반환 GET /api/v1/users/{username}
프로필 정보 수정 Full Name, Bio, Website, Profile Image URL 변경 PATCH /api/v1/users/me
비밀번호 변경 기존 비밀번호 검증 후 새로운 비밀번호로 변경 POST /api/v1/users/me/password
사용자 검색 키워드로 username/full_name 실시간 검색 (팔로우 상태 포함) GET /api/v1/users/search
팔로우 / 언팔로우 1-Click 팔로우 토글 및 팔로워/팔로잉 수 실시간 갱신 POST/DELETE /api/v1/users/{username}/follow
팔로워/팔로잉 목록 해당 유저의 팔로워 및 팔로잉 사용자 리스트 조회 모달 GET /api/v1/users/{username}/followers
📸

4. 게시물 & 피드 엔진 (Posts & Feed)

기능명 기능 설명 엔드포인트 및 구현 특이사항
게시물 작성 이미지 선택, 문구(Caption) 및 위치(Location) 설정 후 등록 POST /api/v1/posts
메인 피드 (타임라인) 내가 팔로우하는 유저들과 나의 최신 게시물을 역순으로 조회 GET /api/v1/posts/feed (페이지네이션 지원)
탐색 피드 (Explore) 인스타그램 탐색 탭 스타일의 인기/최신 게시물 타일 그리드 GET /api/v1/posts/explore
게시물 수정 & 삭제 본인이 작성한 게시물의 문구 수정 및 완전 삭제 (권한 검증) PATCH / DELETE /api/v1/posts/{post_id}
💬

5. 커뮤니티 상호작용 (Likes, Comments, Bookmarks)

❤️ 좋아요 (Likes) System
• 게시물 좋아요 토글: 하트 클릭 시 즉시 UI 업데이트 (Optimistic UI Update)
• 좋아요 유저 목록: 해당 게시물에 좋아요를 누른 유저 리스트 팝업 (UserListModal)
💬 댓글 (Comments) System
• 댓글 작성/조회: 게시물 하단 댓글 모달에서 실시간 작성 및 최신순 목록
• 댓글 좋아요/삭제: 본인 댓글 삭제 및 타인 댓글 좋아요 토글 기능
🔖 북마크 (Bookmarks) System
• 게시물 저장: 리본 아이콘 클릭으로 저장/저장 취소 토글
• 저장된 게시물 탭: 프로필 페이지에서 내가 북마크한 게시물만 별도 모아보기
⭕

6. 24시간 스토리 모듈 (Stories Feature)

기능명 기능 설명 비고
스토리 게시 사진 업로드 및 텍스트/배경색 설정 스토리 생성 (24시간 만료) POST /api/v1/stories
스토리 피드 바 (StoryBar) 메인 피드 상단 안읽음(그라디언트 링) / 읽음(회색 링) 아바타 슬라이더 StoryBar.tsx 컴포넌트
전체화면 스토리 플레이어 프로그레스 바 자동 진행, 좌/우 터치 이동, 전체화면 인터랙션 StoryViewerModal.tsx
읽음 처리 & 조회수 스토리 진입 시 백엔드 읽음 상태 기록 및 총 조회수 갱신 POST /api/v1/stories/{id}/view
🖼️

7. 미디어 업로드 및 최적화 엔진 (Upload Pipeline)

🔄 스마트 EXIF 회전 보정
스마트폰 카메라 촬영 시 포함되는 orientation 메타데이터를 자동으로 인식하여 직립 보정합니다 (Pillow ImageOps.exif_transpose).
📐 1080px 표준 리사이징
4K/초고해상도 이미지를 모바일 인스타그램 표준인 1080px 비율 유지 리사이징을 수행합니다 (LANCZOS 고품질 필터).
⚡ 85% JPEG 용량 최적화
PNG/Paletted 이미지를 RGB JPEG로 투명도 변환 후 85% 품질 압축을 적용하여 모바일 트래픽을 80% 이상 절감합니다.
📡

10. 비기능 요건 & 성능/보안

Bearer JWT 기반 검증, 비밀번호 bcrypt 암호화, CORS 유연 설정 적용.

AsyncSession 비동기 DB 연동, Eager Loading (N+1 방지), 1080px JPEG 미디어 압축.
✨ 반응성 (UX)
Optimistic Updates (좋아요 즉시 반영), 무한 스크롤 & Pull-to-refresh 구현.
